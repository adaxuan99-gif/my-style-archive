# 部署与使用

## 先明确目前的状态

代码是可以连接 Supabase 的完整第一阶段项目，但没有替你开通 Supabase、创建账号、改变账号权限或部署外部服务。实际联网使用还需你确认并完成下列配置。没有连接时页面会显示“待连接”，不能保存数据。

本说明是操作指引，不表示已经替你执行这些外部操作。执行数据库配置之前应确认目标是你新建的空项目；有旧数据请先备份。

## 1. 免费方案与边界

采用 Next.js + TypeScript + Tailwind CSS，数据库、账号和照片使用 Supabase Free，个人非商业部署建议 Vercel Hobby 的免费 `vercel.app` 地址。无需购买域名、服务器或 AI API。**只选择 Free / Hobby，不启用 Pro 试用，不绑定银行卡，不开通任何付费扩展；如果注册页面要求付款或绑卡，停止并重新核对方案。**

## 2. 创建 Supabase 私人项目（需要你的确认）

1. 使用自己的账号登录 [Supabase](https://supabase.com/)，新建组织和项目，选 **Free**。
2. 项目名称填写 `my-style-archive`，选择离你较近、实际可访问的地区。
3. 设置强数据库密码，保存在你的密码管理器里，不发到聊天中。
4. 打开 SQL Editor，把 `supabase/migrations/001_archive.sql` 全部复制进去执行一次。
5. 检查 Table Editor 中有 garments、photos、profiles、categories、number_counters；检查 Storage 的 wardrobe 桶显示 **Private**。
6. 本 SQL 不包含删除旧数据库命令，但它建立账号访问权限和存储策略，须只在你已确认的新项目执行。

SQL 整体在一个事务中执行，失败不会留下部分表。再次执行会报告已有对象，请勿删除已有数据库来解决；先确认之前是否已经成功。

## 3. 创建自己的登录账号

本版是个人长期应用，不开放陌生人自助注册。

1. Authentication → Providers / Sign In 配置中，保留 Email + Password 登录，并关闭允许新用户自行注册的选项。
2. Authentication → Users → Add user / Create user：填写你自己的邮箱和一个强密码，由项目管理员确认邮箱。
3. 不需要增加其他用户或管理员，不需要给前端高权限。
4. 应用使用“邮箱 + 密码”登录。忘记密码时，在你自己的 Supabase 控制台为该用户设置新密码，或按官方密码重置流程操作。

Supabase 默认发信服务只给项目团队中的允许地址发邮件，且有较低的速率限制，不适合承诺公开注册或通用找回密码。为了不增加 SMTP、域名或订阅，本版明确采用控制台管理私人账号。不要为了省事关闭数据权限或改用公开照片桶。

官方来源：[默认邮件服务限制](https://supabase.com/docs/guides/auth/auth-smtp)、[密码登录](https://supabase.com/docs/guides/auth/passwords)。

## 4. 填写配置

从 Supabase Connect / API Settings 找到：

- Project URL：类似 `https://你的项目.supabase.co`。
- Publishable key：一般以 `sb_publishable_` 开头。旧项目可用 `anon` key。

复制 `.env.example` 为 `.env.local`：

```ini
NEXT_PUBLIC_SUPABASE_URL=https://你的项目.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=你的publishable_key
```

这两个值可以进入浏览器，安全由登录和数据库 RLS 负责。**不要填 `service_role`、`sb_secret_`、数据库密码、访问令牌。** `.env.local` 不提交到代码仓库。更改后重启开发服务或重新部署。

## 5. 在电脑运行

安装 Node.js 24 LTS（或 >=22.13），安装 pnpm 11。打开终端进入项目目录后运行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://localhost:3000`。首次需要登录，之后直接进入衣柜。

## 6. 免费部署（需要你的确认）

1. 把项目代码存到你自己的私有 Git 仓库，排除 `.env.local`、照片、备份、node_modules、.next。
2. 在 Vercel 选择 Hobby，导入仓库；框架选择 Next.js。
3. 构建命令 `pnpm build`，安装命令 `pnpm install --frozen-lockfile`，Node 版本 24。
4. 添加上面两条环境变量；不要添加服务密钥。
5. 部署成功后使用自动生成的 HTTPS `vercel.app` 地址。无需购买域名。
6. 在 Supabase Authentication → URL Configuration 中设置你的正式 HTTPS 站点地址，不使用通配的任意域名。
7. 按测试文档逐条验收后再大批录入衣服。

本项目不依赖 Vercel 专属数据库，也可以搬到其他支持 Node 的免费平台；新平台的免费限额要重新确认。中国大陆不同网络对免费海外平台的可达性可能不同，应在你的 iPhone 实测登录与上传再决定长期使用。

## 7. iPhone 添加到主屏幕

Safari 打开正式 HTTPS 地址 → 分享 → 添加到主屏幕 → 名称“我的AI衣橱”。图标、启动背景和底部安全区域已配置。

这是联网使用的 PWA：不会把私密照片写入 Service Worker 缓存，也不支持离线录入。断网时会提示，不会假装保存成功。

拍照上传会调用系统相机；多张照片从相册选择。JPEG/PNG/WebP 可处理；HEIC 是否能读取取决于设备浏览器，失败时会提示转换，不会上传不可读的文件。照片设置为“兼容性最佳”可使用 JPEG。

## 8. 基本使用

- “收录衣服”：名称必填，其余慢慢补。多张照片属于同一件衣服，星形按钮选封面，剪刀裁剪。
- 分类和更多筛选用于查找；输入 `P001` 可按编号找衣服。
- 衣服详情 → 编辑；换分类不会改变旧编号。
- “归档”保留记录和照片；切换“已归档”可以移回。
- “批量管理”可批量分类、加标签、归档或删除；批量上传按每张照片建立一件独立衣服，部分失败有明细。
- 风格档案填好后点保存；初始资料只有第一次保存后才进入数据库。
- “我的”下载完整 ZIP，并确认它确实保存在手机“文件”中。
