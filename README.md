# 我的AI衣橱 · My Style Archive

面向 iPhone 的私人电子衣柜。第一阶段版本：真实 Supabase 数据保存；没有付费 AI、临时演示数据库或自动开通服务。

## 当前可以做什么

- 邮箱密码登录（私人账号由自己的 Supabase 控制台创建，不开放公共注册）。
- 衣服录入、编辑；单件最多 12 张照片；相册多选、直接拍照、方形裁剪、设置封面。
- 自动压缩 JPEG，最长边 1600px，单图不超过 2MB；去掉原图 EXIF 信息。
- 所有要求的衣服资料字段；只强制填写名称与分类。编号由数据库生成且保持稳定。
- 网格 / 列表；名称、编号和标签搜索；分类、颜色、季节、风格筛选。
- 归档、移回衣柜、确认后永久删除；批量分类、标签、归档、删除；每张照片独立建档的批量收录。
- 可修改的初始风格档案、自定义一级分类。
- 完整 ZIP 备份（JSON + CSV + 照片 + SHA-256 校验），恢复、重复导入检查、编号冲突保护、恢复中断重试。
- iPhone 主屏幕安装入口、底部五栏导航与安全区域适配。

## 尚未实现

第二阶段：穿搭实验室、穿搭日记、购物候选、规则查重、实际穿着次数统计。第三阶段：灵感库、风格历史、ChatGPT 分享模板与反馈记录。两个导航入口明确标为尚未开放，没有伪造搭配与统计。

完整恢复虽然原计划属于第三阶段，因“可恢复备份”是长期保存的前提，已在第一阶段交付基本实现。当前 ZIP 只包含本版已经存在的数据，不会声称备份尚未开发的穿搭或购物记录。

## 本地启动

需要 Node.js 22.13+（推荐 Node 24 LTS）以及 pnpm 11，或使用 npm 安装。

```sh
cp .env.example .env.local
# 按 docs/部署与使用.md 配置 Supabase，再填写 .env.local
pnpm install --frozen-lockfile
pnpm dev
```

打开 http://localhost:3000 。未配置时可以查看界面结构与初始风格资料，但不能保存私人资料。

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm start
```

首次运行浏览器测试：`pnpm exec playwright install chromium`，然后 `pnpm test:browser`。

## 项目结构

```
app/                 中文界面、样式、PWA 配置
components/          衣服编辑、裁剪、详情照片、风格、备份设置
lib/                 数据规则、Supabase、图片处理、ZIP 备份
supabase/migrations/ 数据库与安全策略
scripts/             大容量备份与恢复工具
 tests/              数据规则、数据库和浏览器测试
 docs/               中文说明
```

浏览器只保存登录会话，以便下次打开仍能登录；衣服资料和照片始终以独立云数据库为准。不缓存私人照片，不提供离线修改。此项目不包含 service_role 或其他高权限密钥。
